## v7.0 家庭用药安全操作系统（2026-09-06，纯新增不动旧功能）

从「查询 + 提醒工具」升级为「家庭用药安全操作系统」，8 项纯新增功能（v70 前缀，注入各页签卡片，旧代码零改动）：

1. **今日家庭用药总览**（首页置顶）：已打卡/应服药与依从率、家庭成员用药概况、药箱临期与低余量汇总；发现用药问题时顶部出现「AI 安全提醒」横幅并可一键跳转详情。
2. **用药安全画像**（家庭页）：每名成员自动生成安全画像（过敏/体重/孕哺三态），页内展开编辑面板（兼容安卓 WebView，无原生弹窗）；画像参与过敏/疾病/孕哺匹配。
3. **家庭用药安全检查**（相互作用页）：一键检查全家当前用药——两两相互作用、重复成分、过敏风险、疾病相关注意事项（对症治疗药不误报，如降压药用于高血压；妊娠/哺乳期画像自动纳入哺乳/妊娠禁忌匹配）。
4. **智能漏服链**（提醒页）：未确认服药逐条给出「已服/跳过/忘记/不适暂停」；「已服」真实写入旧依从打卡，「忘记」等只记漏服原因不打卡。
5. **药箱库存预测**（提醒页）：按服药计划 × 每次用量估算剩余可用天数，与效期取更紧急者提示；每次用量可单独保存。
6. **药品对比**（首页）：两药成分/用途/用法/禁忌并排对比 + 自动检测常见重复成分；双未收录时明确提示改用通用名。
7. **数据来源脚注**：搜索/说明书/孕哺安全结果卡片自动附带数据来源与纠错指引。
8. **医生就诊报告**（健康页）：一键生成可复制的专业就诊文本（患者信息/用药清单/用药计划/近 7 日漏服），就诊时直接出示。

## ☁️ AI 后端 + 云同步部署（必做，否则 AI 问答与多设备同步不可用）

`worker/ai-worker.js` 是配套的 Cloudflare Worker（v2），同时提供 AI 代理与云端同步：

1. 安装 wrangler：`npm install -g wrangler`，然后 `wrangler login` 完成 Cloudflare 授权。
2. 创建 KV 命名空间：`wrangler kv namespace create PHARMACY_KV`，把输出的 id 填入 `worker/wrangler.toml` 的 `id` 字段。
3. 部署：在 `worker/` 目录执行 `npx wrangler deploy`（会覆盖同名旧 Worker `ai-pharmacy`）。
4. （可选）配置密钥：`wrangler secret put SILICONFLOW_KEY` / `wrangler secret put DASHSCOPE_KEY` / `wrangler secret put AUTH_TOKEN`。
   - **不配置任何密钥也能用**：Worker 自动降级到 pollinations.ai 免密钥通道。
   - 设置 `AUTH_TOKEN` 后，需在 App ⚙️ AI 设置面板填写同一令牌。
5. 在 App ⚙️ → AI 设置中把「服务端代理地址」填为 `https://ai-pharmacy.你的子域.workers.dev`（v5.4 起无需改代码）。
6. 建议在 Cloudflare 开启 WAF 限流（同 IP 每分钟 ≤10 次）防止接口被刷。

### 同步接口速查
- `POST /sync/create` 创建家庭 → 返回 12 位家庭 ID
- `POST /sync/join` 加入家庭 · `POST /sync/put` 上传数据 · `GET /sync/get?familyId=&type=` 拉取数据
- `GET /health` 健康检查（KV 是否绑定、各通道密钥是否配置）
